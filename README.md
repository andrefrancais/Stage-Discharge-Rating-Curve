# Stage-Discharge-Rating-Curve
This is a program created in Matlab App Designer which calculate the height of a given discharge rate in function of some parameters. Then the a plot will be shown on the screen, and an Excel file generated.

There are two releases: one that installs Matlab Runtime and the program can run as a standalone program [release_desktop], and one that can be installed as a Matlab toolbox and called from Matlab Command Window [release_matlab].

Complete the fields with numerical values, press the start button, and the program will generate a table with all the values and will interpolate the height of the installed discharge rate.

To generate the Excel File you need to RUN the program as ADMINISTRATOR.
